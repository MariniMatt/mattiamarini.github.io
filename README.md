# Mattia Marini — Portfolio

Personal portfolio website. It shows two business case studies:

- **TalentOS** — a pitch for an AI-based hiring platform (i3 Contest)
- **Ferretti vs Sanlorenzo** — a financial comparison of two Italian yacht builders (FY2025)

## About

I'm a Business Management & Entrepreneurship student at the University of Charleston (WV). This site collects projects from coursework and business competitions.

## Tech

Single `index.html` file. No framework, no build step. Hosted with GitHub Pages.

## Live site

https://mattiamarini.github.io

## Update

To update the content, replace `index.html` with a new version and push the change. GitHub Pages updates automatically.
